# 当前实现状态与已知问题

最后更新日期：2026-07-30

## 1. 当前已实现

### 工作台

- 房态工作台主页面
- 院落切换
- 房态筛选
- 楼栋列表
- 结构管理编辑态
- 新增院落 / 楼栋 / 楼层 / 房间
- 删除房间
- 顶部区吸顶，继续做文案清理中

### 楼栋详情

- 查看楼栋下楼层与房间
- 点房间进入房间详情或办理入住

### 房间详情

- 当前情况与历史入住双视图
- 时间轴展示历史入住情况
- 收房租
- 收水电
- 抄表生成杂费
- 灵活收费
- 退租
- 档案、房屋照片与收款凭证支持从手机相册选择并预览
- 收款凭证、抄表照片、身份证、合同和房屋照片均为可选附件，不阻断收费或入住
- 与办理入住之间的页面跳转已改为更保守的前进策略

### 办理入住

- 录入租客信息
- 设置租期与周期
- 计算支付计划
- 支持选择身份证、合同和房屋照片；附件均为可选
- 租客姓名、手机号、租金、押金、支付周期、租期开始和月数具备必要校验
- 入住完成后跳转房间详情

### 账务

- 已改为历史流水页，不再突出待收视图
- 顶部展示累计实收、房租实收、水电实收、灵活实收
- 支持按类型筛选历史流水
- 支持按房号 / 租客搜索
- 支持凭证预览抽屉
- 支持跳转对应房间详情

### 我的

- 顶部个人信息卡已统一为深色头卡
- 首页菜单重做为双分组卡片布局
- 支持租客档案搜索与预览入口
- 支持默认水电模板设置
- 支持电子合同模板入口
- 支持提醒机制设置
- 支持导出页入口
- 支持重置 demo 数据
- 二级页中文文案已大幅清理

### 通用能力

- 原生小程序 tabBar
- 路由节流与防重入
- mock 数据本地持久化
- 抽屉组件
- 时间轴组件
- 路由锁已调整为 success 释放 + 超时兜底，避免连续跳转导致路由栈异常
- 收费、入住收费、押金收费统一使用公共收费弹层
- 收费表格组件采用隔离样式，避免房间详情中的同名样式互相覆盖
- 移动端最小辅助字号基线：`text-2xs` 为 12px，`text-3xs` 为 10px
- 非功能性卡片、抽屉、弹层和导航描边已收敛；输入、上传、空状态和必要表格分隔仍保留边框

## 3. 已知问题

### 高优先级

- 仓库里仍有部分历史文件与 mock 文案存在乱码污染，尤其是工作台和部分底层 mock 文案
- 结构管理页和部分房间页还需要继续精修，和原型仍有差距
- 虽然已收紧路由策略，但仍建议继续观察小程序里是否还有 `webviewId not found` 类错误

### 中优先级

- `wx.getSystemInfoSync` 仍在使用，开发者工具会给出弃用警告
- 构建链路仍依赖 WXSS 清理脚本
- 当前以本地持久化为主；云端 API、数据库和对象存储尚未作为稳定生产链路启用
